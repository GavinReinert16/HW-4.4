The purpose is to practice using GitHub and learn how to organize projects, track changes, and collaborate using version control.

Data Source

The files in this repository are related to the course assignment. Any data used comes from the provided course materials.

Project Plan

The goals of this project are:

Organize assignment files.
Practice using GitHub branches.
Track changes through commits.
Create and merge pull requests.
Use GitHub Issues to organize tasks.
Keep the main branch updated.
Repository Organization

The repository is organized into the following sections:

README.md: Provides an overview of the project.
Assignment files: Contains the files used for the assignment.
main: The primary branch containing finalized work.
dev: The development branch used to make changes before merging.
